# A bug? Report it on GitHub
Something breaks, crashes or does the wrong thing: please report it on GitHub, where bugs are tracked until they are fixed: <https://github.com/Przemotar/hubdeck/issues/new?template=bug.yml>

In HubDeck, **Help and feedback > Report a problem** opens that form with your version, system and modules filled in. Attach the diagnostics file (**Help and feedback > Save diagnostics**, or the tray icon's menu): it has versions, modules and the log, with web addresses, keys, paths and serial numbers removed.

Questions about setting things up are welcome here. Answers usually come within about a day; HubDeck is made by one person.
